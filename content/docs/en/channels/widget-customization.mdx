# Widget customization

The Yoosr widget adapts to your brand. You can change its color, position, logo, header text, welcome message, and the language visitors see — all from **Settings → Widget Setup** without touching code.

## Primary color

The primary color is applied to the launcher button, the send button, and the chat header background. Enter any valid CSS hex color code — for example `#2563eb`.

Changes take effect immediately. The widget fetches its configuration from Yoosr at load time, so visitors see the new color on the next page load.

## Widget position

By default, the widget button appears in the **bottom-right** corner of the screen. Change the `align` setting to **left** if another element in your layout occupies that position.

| Align value | Button position |
|-------------|-----------------|
| `right` (default) | Bottom-right |
| `left` | Bottom-left |

## Logo

Upload a square image (PNG or SVG, minimum 64 × 64 px) to replace the default Yoosr icon in the chat header. The logo appears at the top of the open chat window, next to the header title.

## Header title

The header title is the name displayed at the top of the chat window. Set it per language if your visitors use multiple locales.

| Language | Field key |
|----------|-----------|
| English | `headerTitle.en` |
| Arabic | `headerTitle.ar` |
| French | `headerTitle.fr` |

If a translation for the active locale is missing, the widget falls back to the English value.

## Welcome message

The welcome message appears as the first message in the chat window before the visitor sends anything. It is sent as a bot message with type `system` and content key `system.welcome`.

To customize the text, set `widgetConfig.translations.welcomeMessage` per locale in Widget Setup. To disable the welcome message entirely, set **Enable welcome notification** to off.

| Setting | Behavior |
|---------|----------|
| `enableWelcomeNotification: true` | Welcome message appears when the conversation starts |
| `enableWelcomeNotification: false` | No welcome message — visitor sees an empty chat window |

## Online status text

The online status line appears below the header title. It is a short phrase like "We usually reply in a few minutes." Set it per locale using the `onlineStatus` translation field in Widget Setup.

## Language and locale

The widget language is set at two levels:

**Project-level locale** — Set `widgetLocale` in **Settings → Widget Setup → Language**. This applies to every visitor who opens the widget on your site. Supported values: `en` (English), `ar` (Arabic), `fr` (French).

**Page-level override** — Pass a `lang` query parameter when embedding the widget script, for example:

```html
<script>
  window.yoosrSettings = { projectId: "YOUR_PROJECT_ID" };
</script>
<script src="https://app.yoosr.com/widget.js?lang=ar" async></script>
```

<Callout variant="info" title="URL parameter takes priority">
If both a project-level `widgetLocale` and a `lang` URL parameter are set, the `lang` parameter takes priority. Use this to serve a different locale on a specific page — for example, an Arabic-language landing page — without changing the project-wide setting.
</Callout>

## Right-to-left layout

When Arabic is active — either from `widgetLocale` or the `lang` parameter — the widget automatically switches to a right-to-left layout. All text, the input field, and the send button flip direction without any additional configuration.

## Pre-chat form labels

The labels on the pre-chat form — the form title, subtitle, and the start chat button — are customizable per locale using the following translation fields:

- `preChatTitle` — Heading shown above the form
- `preChatSubtitle` — Secondary text below the heading
- `startChat` — Label on the submit button

Set these in **Settings → Widget Setup → Translations**.
