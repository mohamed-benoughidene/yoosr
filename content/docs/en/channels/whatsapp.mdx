# WhatsApp

Connect WhatsApp to Yoosr using the WhatsApp Business Cloud API through Meta for Developers. Once connected, inbound WhatsApp messages create conversations in your dashboard and your agents can reply directly without leaving Yoosr.

## Prerequisites

Before you start, make sure you have:

- A Meta Developer account at [developers.facebook.com](https://developers.facebook.com)
- A WhatsApp Business Account (WABA) linked to your Meta Developer account
- A verified phone number — a test number from Meta works during development

## Step 1: Create a Meta app

1. Go to [Meta for Developers](https://developers.facebook.com) and sign in.
2. Select **My Apps** → **Create App**.
3. Choose **Business** as the app type.
4. Add the **WhatsApp** product to your app.

## Step 2: Get your credentials

In your Meta App, go to **WhatsApp → API Setup**. Collect these two values:

| Credential | Where to find it |
|------------|-----------------|
| Phone Number ID | Listed under API credentials |
| Temporary Access Token | Generate one with `whatsapp_business_messaging` permission |

<Callout variant="warning" title="Temporary tokens expire">
Temporary access tokens are short-lived. For a production deployment, create a System User in your Meta Business Manager and generate a long-lived token instead.
</Callout>

## Step 3: Configure in Yoosr

1. In the Yoosr dashboard, go to **Settings → Channels**.
2. Find **WhatsApp** and select **Connect**.
3. Enter your **Phone Number ID** and **Access Token**.
4. Yoosr generates a **Verify Token** automatically.
5. Select **Save**.

## Step 4: Set the webhook in Meta

1. In your Meta App, go to **WhatsApp → Configuration** → **Webhook** → **Edit**.
2. Paste the **Callback URL** shown in Yoosr — it looks like `https://<your-convex-site>.convex.site/webhooks/meta`.
3. Paste the **Verify Token** from Yoosr.
4. Select **Verify and Save**.
5. Subscribe to these webhook events: `messages`, `message_status`, `reads`.

## Step 5: Test the connection

Use the test phone number in your Meta App to send a message to your business number. Within seconds a conversation appears in the Yoosr dashboard with the WhatsApp channel indicator. Reply from the dashboard — your reply arrives on WhatsApp.

## How it works

| Step | What happens |
|------|-------------|
| Visitor messages your number | Meta sends a POST to your Yoosr webhook |
| Yoosr receives it | Verifies the `X-Hub-Signature-256` HMAC-SHA256 signature |
| Deduplication | Yoosr checks the `messageId` to prevent duplicate records |
| Conversation created | Contact and conversation records are created or matched |
| Agent replies | Yoosr sends the reply to Meta's WhatsApp `sendMessage` API |

## Security

All webhook requests from Meta are signed with `X-Hub-Signature-256`. Yoosr verifies this signature using your stored app secret, which is encrypted with AES-GCM before being written to the database. Verification uses timing-safe comparison to prevent timing attacks. Yoosr always responds with `200 OK` per Meta's requirements to prevent retries.

## Troubleshooting

| Problem | Fix |
|---------|-----|
| Webhook verification fails | Check that the Verify Token in Meta matches the one Yoosr generated |
| Messages not arriving | Confirm the webhook subscription includes the `messages` event |
| `403 Forbidden` | The app secret is wrong — re-enter it in Yoosr channel settings |
| Replies not sending | Verify the access token has `whatsapp_business_messaging` permission and has not expired |
