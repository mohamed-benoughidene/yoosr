# WhatsApp Integration

Connect WhatsApp to Yoosr using the **WhatsApp Business Cloud API** through Meta for Developers. This enables you to receive and respond to WhatsApp messages from your agent dashboard.

## Prerequisites

- A **Meta Developer** account ([developers.facebook.com](https://developers.facebook.com))
- A **WhatsApp Business Account** (WABA) linked to your Meta Developer account
- A **verified phone number** (can be a test number during development)

## Step 1: Create a Meta App

1. Go to [Meta for Developers](https://developers.facebook.com)
2. Click **My Apps** → **Create App**
3. Select **Business** as the app type
4. Fill in the app name and contact email
5. Add the **WhatsApp** product to your app

## Step 2: Get Credentials

In your Meta App dashboard, under **WhatsApp → API Setup**:

| Credential | Where to find it |
|------------|-----------------|
| **Phone Number ID** | API Setup page, under "API credentials" |
| **Temporary Access Token** | API Setup page, generate a token with `whatsapp_business_messaging` permission |

## Step 3: Configure in Yoosr

1. Go to **Settings → Channels** → **WhatsApp** → **Connect**
2. Enter your **Phone Number ID**
3. Enter your **Access Token**
4. Yoosr generates a **Verify Token** for webhook verification
5. Click **Save**

## Step 4: Configure the Webhook

In your Meta App:

1. Go to **WhatsApp → Configuration**
2. Under **Webhook**, click **Edit**
3. Paste the **Callback URL** from Yoosr (e.g., `https://<your-convex-site>.convex.site/webhooks/meta`)
4. Paste the **Verify Token** from Yoosr
5. Click **Verify and Save**
6. Subscribe to these webhook events:
   - `messages`
   - `message_status`
   - `reads`

## Step 5: Test

1. Use the test phone number in your Meta App to send a message to your business number
2. A conversation should appear in your Yoosr dashboard
3. Reply from the dashboard — the reply arrives on WhatsApp

## How It Works

| Step | What happens |
|------|-------------|
| User messages your number | Meta POSTs the message to your Yoosr webhook |
| Yoosr receives it | Verifies `X-Hub-Signature-256` HMAC-SHA256 signature |
| Deduplicates | By `messageId` to prevent duplicate conversations |
| Creates conversation | Matches or creates contact + conversation records |
| Agent replies | Yoosr POSTs to Meta's WhatsApp sendMessage API |

## Security

- **HMAC-SHA256 verification**: Every webhook request is signed with `X-Hub-Signature-256` using your app secret (encrypted with AES-GCM)
- **Constant-time comparison**: Signature verification uses timing-safe comparison to prevent timing attacks
- **Always 200**: Yoosr returns `200 OK` per Meta requirements to prevent retries

## Troubleshooting

| Issue | Fix |
|-------|-----|
| Webhook verification fails | Ensure the Verify Token matches between Meta and Yoosr |
| Messages not arriving | Check webhook subscription includes `messages` event |
| `403 Forbidden` | The app secret doesn't match — re-enter it in Yoosr channel settings |
| Can't send replies | Verify the access token has `whatsapp_business_messaging` permission and hasn't expired |

<Callout variant="warning" title="Token expiration">
Temporary access tokens expire. For production, use a **System User** with a long-lived access token. See Meta's documentation for details.
</Callout>
