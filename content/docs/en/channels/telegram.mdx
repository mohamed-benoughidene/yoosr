# Telegram

Connect your Telegram bot to Yoosr so messages sent to it appear as conversations in your agent dashboard. Telegram is the recommended channel for MENA-region deployments — it requires no business verification and setup takes about five minutes.

## Step 1: Create a Telegram bot

1. Open Telegram and search for **@BotFather**.
2. Send the command `/newbot`.
3. Choose a display name — for example, `Acme Support`.
4. Choose a username ending in `bot` — for example, `acme_support_bot`.
5. BotFather sends you a **Bot Token** that looks like `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`.

<Callout variant="warning" title="Keep your token secret">
Anyone who has your bot token can control your bot. Never share it publicly or commit it to a code repository.
</Callout>

## Step 2: Configure in Yoosr

1. In the Yoosr dashboard, go to **Settings → Channels**.
2. Find **Telegram** and select **Connect**.
3. Paste your **Bot Token**.
4. Yoosr generates a **Secret Token** automatically.
5. Select **Save**.

Make a note of the **Webhook URL** and **Secret Token** shown after saving — you need both in the next step.

## Step 3: Set the webhook

Tell Telegram where to send messages by opening this URL in your browser (replace the three placeholders):

```
https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=<YOOSR_WEBHOOK_URL>&secret_token=<SECRET_TOKEN>
```

| Placeholder | Value |
|------------|-------|
| `<YOUR_BOT_TOKEN>` | The token from BotFather |
| `<YOOSR_WEBHOOK_URL>` | The Webhook URL shown in Yoosr channel settings (typically `https://<your-convex-site>.convex.site/webhooks/telegram`) |
| `<SECRET_TOKEN>` | The Secret Token Yoosr generated |

A successful response looks like:

```json
{ "ok": true, "result": true, "description": "Webhook was set" }
```

## Step 4: Test the connection

Send a message to your Telegram bot. Within seconds:

1. A new conversation appears in the Yoosr dashboard.
2. The conversation shows the Telegram channel indicator.
3. The contact is created with the Telegram user's display name.

Reply from the Yoosr dashboard — your reply arrives in the Telegram conversation.

## How it works

| Step | What happens |
|------|-------------|
| User messages the bot | Telegram sends a POST to your Yoosr webhook |
| Yoosr receives it | Verifies the `X-Telegram-Bot-Api-Secret-Token` header |
| Conversation created | Contact and conversation records are created or matched |
| Routing runs | Bot → available agents → unassigned queue |
| Agent replies | Yoosr calls Telegram's `sendMessage` API to deliver the reply |

## Security

Every webhook request from Telegram is authenticated using the `X-Telegram-Bot-Api-Secret-Token` header, which Yoosr matches against the stored secret token. Only POST requests are accepted — GET requests return `405 Method Not Allowed`. Yoosr always responds with `200 OK` to prevent Telegram from retrying failed deliveries.

## Troubleshooting

| Problem | Fix |
|---------|-----|
| Messages not arriving | Call `https://api.telegram.org/bot<TOKEN>/getWebhookInfo` and verify the URL matches your Yoosr webhook URL |
| `403 Forbidden` | The secret token does not match — re-save the channel configuration in Yoosr to regenerate it, then set the webhook again |
| Bot token invalid | Test with `https://api.telegram.org/bot<TOKEN>/getMe` — a valid token returns your bot's info |
| Bot does not respond to visitors | Check that an active bot or available agent is configured to handle conversations on this project |
