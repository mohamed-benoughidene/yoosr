# The Chat section

The Chat section is your personal inbox. Unlike the Monitor — which shows every open conversation across your whole team — the Chat section shows only the conversations assigned to you.

This makes Chat the right place to work when you want to focus on your own queue without the noise of the full team view.

## What you see in Chat

The left panel lists all conversations where you are the assigned agent. Each row shows:

- The visitor's name (or "Unknown" if no name was captured)
- A channel icon indicating where the message came from (widget, WhatsApp, Messenger, Instagram, Telegram)
- The last message snippet
- How long ago the last message arrived
- A small blue dot if there are unread messages

Clicking a row opens the full conversation in the middle panel. The right panel shows the visitor's contact info, exactly the same as in Monitor.

## The All and Unread tabs

At the top of the conversation list there are two tabs:

**All** — Every conversation assigned to you, including ones you have already replied to and ones marked as resolved.

**Unread** — Only conversations where the visitor has sent a message you have not read yet. The tab shows a count so you can see at a glance how many need attention. When you open a conversation, it is automatically marked as read after half a second.

## Search

The search bar filters by visitor name or last message content. It searches as you type — no need to press Enter.

## How Chat differs from Monitor

| | Chat | Monitor |
|---|---|---|
| Conversations shown | Only assigned to you | All open conversations |
| Filters | Tab + search only | Label, department, agent, status, sort |
| Joining | Not needed — already assigned | Join button to take a conversation |
| Best for | Working your personal queue | Managing the full team queue |

Use Monitor when you need to see the whole picture or pick up unassigned conversations. Use Chat when you want to focus and work through your own list.
