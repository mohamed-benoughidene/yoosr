# Widget Installation

The Yoosr widget is a lightweight JavaScript component that adds a live chat button to your website. It loads asynchronously, so it won't impact page performance.

## How It Works

Every installation follows the same pattern:

1. Set `window.yoosrSettings` with your Project ID
2. Load the `widget.js` script from your app's origin

The script reads your config, creates a launcher button, and embeds an iframe connected to your Yoosr project.

## Find Your Project ID

Before installing, you need your **Project ID**:

1. Go to **Settings → Widget Setup** in your dashboard
2. Switch to the **Installation** tab
3. Your Project ID is pre-filled in the code snippet

---

## HTML / Standard

Paste these two lines before the closing `</body>` tag in your HTML:

```html
<script>
  window.yoosrSettings = { projectId: "proj_abc123xyz" };
</script>
<script src="https://app.yoosr.com/widget.js" async></script>
```

**Where to paste:** Any `.html` file, right before `</body>`.

---

## Next.js

Use `next/script` for optimal loading in the App Router:

```tsx
import Script from 'next/script'

export default function Layout({ children }) {
  return (
    <html>
      <body>
        {children}
        <Script id="yoosr-init" strategy="afterInteractive">
          {`window.yoosrSettings = { projectId: "proj_abc123xyz" };`}
        </Script>
        <Script src="https://app.yoosr.com/widget.js" strategy="afterInteractive" />
      </body>
    </html>
  )
}
```

**Where to paste:** Your root `layout.tsx` or a shared layout component.

<Callout variant="tip" title="Why afterInteractive?">
The `afterInteractive` strategy ensures the widget loads after the page is hydrated, avoiding conflicts with React's rendering.
</Callout>

## React

Use a `useEffect` hook to inject the script dynamically with cleanup on unmount:

```tsx
import { useEffect } from 'react'

export function YoosrWidget() {
  useEffect(() => {
    const id = 'yoosr-widget-sdk';
    let script = document.getElementById(id);
    let created = false;

    if (!script) {
      window.yoosrSettings = { projectId: "proj_abc123xyz" };
      script = document.createElement('script');
      script.id = id;
      script.src = 'https://app.yoosr.com/widget.js';
      script.async = true;
      document.body.appendChild(script);
      created = true;
    }

    return () => {
      if (created && script?.parentNode) {
        script.parentNode.removeChild(script);
      }
    };
  }, []);

  return null;
}
```

**Where to use:** Render `<YoosrWidget />` once in your root component or layout.

## Vue.js

Use `onMounted` and `onUnmounted` for lifecycle management:

```vue
<script setup>
import { onMounted, onUnmounted } from 'vue'

const SCRIPT_ID = 'yoosr-widget-sdk'
let scriptEl = null
let createdHere = false

onMounted(() => {
  scriptEl = document.getElementById(SCRIPT_ID)
  if (!scriptEl) {
    window.yoosrSettings = { projectId: "proj_abc123xyz" };
    scriptEl = document.createElement('script')
    scriptEl.id = SCRIPT_ID
    scriptEl.src = 'https://app.yoosr.com/widget.js'
    scriptEl.async = true
    document.body.appendChild(scriptEl)
    createdHere = true
  }
})

onUnmounted(() => {
  if (createdHere && scriptEl?.parentNode) {
    scriptEl.parentNode.removeChild(scriptEl)
  }
})
</script>
```

**Where to use:** Add to your `App.vue` or root component.

## Nuxt.js

Configure the script in `nuxt.config.ts`:

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  app: {
    head: {
      script: [
        { innerHTML: `window.yoosrSettings = { projectId: "proj_abc123xyz" };` },
        { src: 'https://app.yoosr.com/widget.js', async: true }
      ]
    }
  }
})
```

**Where to configure:** `nuxt.config.ts` at the project root.

## Angular

Add the script tags to `index.html` before the closing `</body>` tag:

```html
<!-- index.html -->
<body>

```

**Where to paste:** `src/index.html`, before `</body>`.

## WordPress (PHP)

Add a function to your theme's `functions.php` that hooks into `wp_footer`:

```php
// In your theme's functions.php
function yoosr_widget() { ?>
  <script>
    window.yoosrSettings = { projectId: "proj_abc123xyz" };
  </script>
  <script src="https://app.yoosr.com/widget.js" async></script>
<?php }
add_action('wp_footer', 'yoosr_widget');
```

**Where to paste:** `wp-content/themes/your-theme/functions.php`.

<Callout variant="tip" title="Using a child theme?">
Add the code to your child theme's `functions.php` to avoid losing changes on parent theme updates.
</Callout>

## Google Tag Manager

Create a Custom HTML tag with this IIFE pattern:

```html
<!-- GTM: New Tag > Custom HTML, trigger: All Pages -->
<script>
(function(d) {
  window.yoosrSettings = { projectId: "proj_abc123xyz" };
  var s = d.createElement('script');
  s.src = 'https://app.yoosr.com/widget.js';
  s.async = true;
  s.onload = function() {
    window.dataLayer = window.dataLayer || [];
    window.dataLayer.push({ event: 'yoosr_widget_loaded' });
  };
  d.body.appendChild(s);
})(document);
</script>
```

**Where to configure:** GTM → New Tag → Custom HTML → Trigger: All Pages → Publish.

<Callout variant="info" title="GTM Event">
The `yoosr_widget_loaded` event is pushed to the data layer when the widget script finishes loading. You can use this as a trigger for analytics.
</Callout>

## Verify the Installation

After installing, check these things:

1. **Chat button visible** — A circular button appears in the bottom-right (or left) corner
2. **Opens on click** — Clicking the button opens the chat window
3. **Welcome message** — After the configured delay, a welcome message appears
4. **Messages send** — You can type and send messages
5. **Dashboard sync** — Messages appear in your Yoosr dashboard

<Callout variant="warning" title="Testing tip">
Use an incognito/private window to simulate a new visitor. The widget stores a visitor ID in `localStorage` to resume sessions.
</Callout>

## Troubleshooting

| Issue | Cause | Fix |
|-------|-------|-----|
| Widget not showing | Script not loaded | Verify the script tag is before `</body>` and the URL is correct |
| CORS error | Wrong origin | Make sure `widget.js` is served from your app's origin, not a different domain |
| "projectId is missing" | Config not set | Ensure `window.yoosrSettings` is defined **before** the script loads |
| Widget style broken | CSS conflict | The widget renders inside an isolated iframe — check for iframe-level issues |
| Messages don't send | Convex endpoint unreachable | Check network tab for failed requests to your Convex site URL |
