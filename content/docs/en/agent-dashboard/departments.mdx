# Departments

Departments let you group agents by function — for example, Sales, Support, or Billing — and route conversations to the right group automatically. Each department has its own routing mode, optional bot assignment, and metadata tags.

<Callout variant="info" title="Admin only">
Only admins can create, edit, or delete departments.
</Callout>

## Create a department

1. Go to **Settings → Departments**.
2. Select **New Department**.
3. Fill in the fields described below.
4. Select **Save**.

## Department fields

### Name and description

The name appears in the Monitor filters and in the transfer dialog when agents route conversations between departments. Choose a name that is unambiguous to your whole team.

The description is internal — it helps your team understand the purpose of the department.

### Routing mode

Choose how new conversations assigned to this department are distributed:

| Mode | Behavior |
|------|---------|
| **Assigned** | The routing engine selects one agent using the least-busy algorithm. One agent is responsible. |
| **Pooled** | The conversation is placed in the shared queue. Any agent in the department can claim it. |

### Bot

Optionally assign a bot to handle conversations in this department. When a conversation is routed to this department, the selected bot runs its flow first. If the bot reaches an HITL Handoff block, the conversation is passed to a human agent.

If no bot is selected, the conversation goes directly to human agents.

### Tags

Tags are free-text metadata labels stored on the department record. They are used for internal routing logic and department metadata — for example, `language:arabic` or `capability:technical`. These are separate from conversation labels.

Add a tag by typing in the tag field and pressing Enter. Remove a tag by selecting the × beside it.

## Managing members

Each department has a member list. To add a member:

1. Select the department row to expand it, or select the edit icon.
2. In the Members popover, select the agents you want to add.

To remove a member, select the × beside their name.

Members determine which agents receive notifications and are eligible for least-busy assignment within this department.

## Edit and delete

To edit a department, select the pencil icon on its row. All fields can be updated. Changes apply immediately to new conversations — existing conversations are not rerouted.

To delete a department, select the trash icon. Deleting a department does not delete the conversations that were routed to it. Those conversations remain but lose the department reference.
