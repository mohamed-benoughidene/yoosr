# Canned responses

Canned responses are pre-written message templates that agents insert into the reply box with a `/` trigger. They reduce the time spent typing common answers and help the team communicate consistently.

<Callout variant="info" title="Admin only">
Only admins can create, edit, and delete canned responses.
</Callout>

## Create a canned response

1. Go to **Settings → Canned Responses**.
2. Select **New Response**.
3. Fill in the fields:

| Field | Description |
|-------|-------------|
| **Title** | Internal name shown in the picker. Use something descriptive — for example, "Refund policy". |
| **Shortcut** | The trigger word agents type after `/`. Must be a single word with no spaces — for example, `refund`. |
| **Content** | The full reply text. Can include line breaks and placeholders. |

4. Select **Save**.

## Using a canned response

In any conversation reply box in Monitor or Chat:

1. Type `/` followed by the shortcut — for example, `/refund`.
2. A picker appears showing matching responses.
3. Select the response or press **Enter** to insert it.
4. Edit the text if needed, then send.

The picker filters results as you type after the `/`, so you can type `/ref` to see all responses whose shortcut starts with "ref".

## Using placeholders

Canned responses support manual placeholders — text that agents replace before sending. Use square brackets to mark them:

```
Hi [CUSTOMER NAME],

Your order #[ORDER NUMBER] has been dispatched.
Tracking reference: [TRACKING NUMBER]

Expected delivery: [DATE]
```

Yoosr does not auto-fill these — the agent replaces them manually before sending. This keeps templates flexible without introducing complex variable syntax.

## Edit and delete

To edit a canned response, select the pencil icon on its row in the table. You can update any field. Changes apply immediately.

To delete a canned response, select the trash icon. Deletion removes the response from the list — it does not affect messages already sent using it.

## Tips for an effective canned response library

Keep shortcuts short and easy to remember. Agents type these under pressure, so `refund` is better than `refundpolicy2024`.

Review the library quarterly. Remove responses that are no longer accurate, update those that reference outdated information, and add new ones for questions that recur frequently.
