# Labels

Labels are color-coded tags that agents and bots attach to conversations to categorize them. They appear as colored badges in the Monitor conversation list and can be used to filter, search, and report on conversation patterns.

<Callout variant="info" title="Admin only">
Only admins can create and delete labels. All agents can apply and remove labels on conversations.
</Callout>

## Create a label

1. Go to **Settings → Labels**.
2. Select **New Label**.
3. Enter a **Name** — this is the text displayed on the badge.
4. Select a **Color** from the dropdown. The color is used for the badge background throughout the dashboard.
5. Select **Save**.

The label is now available to all agents and to the bot engine's **Apply label** block.

## Applying labels to conversations

Agents apply labels in the contact info panel on the right side of Monitor:

1. Select a conversation.
2. In the contact info panel, select the **+** button in the Labels section.
3. A popover shows all available labels. Select one to apply it.
4. The label appears as a badge on the conversation and in the conversation list.

To remove a label, select the **×** on the badge in the contact info panel.

## Filtering by label

In the Monitor conversation list, use the **Label** filter to show only conversations with a specific label. Combine the label filter with status, department, or agent filters to narrow the list further.

## Keeping your label list manageable

Labels are most useful when the list is short and each label has a clear, distinct purpose. A label list with 30 entries becomes hard to use consistently.

A practical starting set for a support team might include labels such as: Billing, Technical, Feature request, VIP, and Escalated. Add new labels only when a consistent category is emerging in your conversations that none of the existing labels covers.

## Edit and delete

To rename a label or change its color, select the edit icon on its row. Renaming updates the label everywhere it appears.

To delete a label, select the trash icon. Deletion removes the label from all conversations that currently have it. This action cannot be undone.
