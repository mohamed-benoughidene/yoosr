# Agent Dashboard

The Agent Dashboard is your team's **command center** — a unified workspace for managing customer conversations across all channels.

## What You Can Do

| Feature | Description |
|---------|-------------|
| **Conversation Management** | View, filter, reply to, and close conversations |
| **Assignment** | Assign conversations to specific agents |
| **Departments** | Group agents into teams with routing rules |
| **Labels** | Tag conversations for categorization |
| **Canned Responses** | Pre-written reply templates with shortcuts |
| **Contacts** | View visitor history and contact details |
| **Analytics** | CSAT ratings, token usage, activity logs, metrics |

## Roles

| Role | Permissions |
|------|------------|
| **Admin** | Full access — settings, team management, billing, integrations |
| **Agent** | Conversations, contacts, labels, canned responses, department view |

Roles are managed through **Clerk organization membership**. Admins have the `org:admin` role.

## Dashboard Layout

The dashboard consists of:

- **Sidebar** — Navigation between sections (Home, Conversations, Contacts, Labels, etc.)
- **Main view** — The active page's content
- **Header** — Project selector, notifications, user menu

## Home View

The home dashboard shows:

| Widget | Description |
|--------|-------------|
| **Stats** | Open conversations, CSAT score, messages today |
| **Recent Conversations** | Latest activity with status indicators |
| **Activity Log** | Recent assignments, closures, and system events |
