# Agent dashboard

The agent dashboard contains the tools your team uses to organize and manage conversations. Beyond the Monitor itself, these features help you categorize, respond faster, and route conversations to the right people.

## What you can configure

**Departments** — Create teams within your organization. Route conversations to specific departments based on the visitor's needs.

**Labels** — Color-coded tags for categorizing conversations. Use them to filter, search, and report on conversation patterns.

**Canned responses** — Pre-written replies for common questions. Agents insert them with a click to save typing time.

**Contacts** — A directory of all visitor profiles. Search, import, and export contact records.

**Orders** — Track and manage customer orders linked to conversations.
