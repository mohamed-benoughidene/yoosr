# Conversations

The Conversations page is where agents spend most of their time — reading and replying to customer messages from all channels.

## Conversation List

The list view shows all conversations with:

| Column | Description |
|--------|-------------|
| **Contact** | Visitor name or "Unknown" |
| **Preview** | Last message snippet |
| **Status** | Open, Pending, Closed, Spam |
| **Channel** | Widget, Telegram, WhatsApp, Messenger, Instagram |
| **Assigned To** | Agent name or "Unassigned" |
| **Labels** | Color-coded tags |
| **Time** | Last activity timestamp |

### Filters & Sorting

Filter conversations by:

- **Status** — Open, Pending, Closed, Spam
- **Channel** — Specific platform
- **Department** — Team assignment
- **Label** — Custom tags
- **Agent** — Assigned person

Sort by:

- **Newest first** (default)
- **Oldest first**
- **Priority** — Manually prioritized

## Conversation Detail

Click a conversation to open the full view:

### Message Thread

- **Chronological messages** from visitor and agents
- **Channel indicator** shows source platform
- **Agent messages** show the sender's name
- **Internal notes** — visible only to agents, not the visitor

### Reply Box

- **Rich text input** for composing replies
- **File attachments** — upload images and documents
- **Canned responses** — type `/` followed by shortcut to insert
- **Send as** — reply as yourself or on behalf of the department

### Right Panel — Contact Info

- **Visitor details** — name, email, phone, visitor ID
- **Conversation history** — past conversations with this contact
- **Labels** — add/remove tags
- **Assignment** — change the assigned agent

## Conversation Statuses

| Status | Meaning |
|--------|---------|
| **Open** | Active conversation needing attention |
| **Pending** | Waiting on external action (bot processing, webhook delay) |
| **Closed** | Resolved — visitor can rate the experience |
| **Spam** | Marked as spam — excluded from metrics |

### Closing a Conversation

1. Click the **Close** button
2. The status changes to **Closed**
3. The visitor receives a closure notification
4. A **CSAT rating prompt** appears for the visitor

## Assignment

Assign conversations to agents:

1. Click the **Assign** dropdown in the conversation header
2. Select an agent from your organization
3. The agent receives a notification (push or email)
4. The conversation moves to their queue

<Callout variant="tip" title="Auto-assignment">
If departments are configured with routing rules, conversations can be auto-assigned based on the channel or topic.
</Callout>

## Labels

Apply labels to categorize conversations:

1. Click the **Label** icon in the right panel
2. Select existing labels or create a new one
3. Labels appear as colored badges in the list view

See [Labels](/docs/agent-dashboard/labels) for detailed management.

## Bulk Actions

Select multiple conversations to:

- **Assign** to an agent
- **Add labels** in bulk
- **Close** all selected
- **Mark as spam**

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + K` | Open command palette |
| `Ctrl/Cmd + Enter` | Send message |
| `e` | Edit conversation status |
| `a` | Open assignment dropdown |
