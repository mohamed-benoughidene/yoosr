# Embed your first widget

The Yoosr widget is a chat button that appears on your website. When a visitor clicks it, they can send messages directly to your team. The widget loads in the background — it will not slow down your page.

The entire installation is two lines of HTML.

## What you need

- Your **Project ID** (find it in **Settings → Widget Setup**)
- Access to your website's HTML

## Installation

### Step 1 — Copy your snippet

In your Yoosr dashboard:

1. Go to **Settings → Widget Setup**.
2. Click the **Installation** tab.
3. Click **Copy** to copy your personal snippet.

It looks like this:

```html
<script>
  window.yoosrSettings = { projectId: "YOUR_PROJECT_ID" };
</script>
<script src="https://app.yoosr.com/widget.js" async></script>
```

Your actual Project ID is pre-filled — you do not need to change anything.

### Step 2 — Paste it on your website

Open your website's HTML and paste the snippet just before the closing `</body>` tag:

```html
<!DOCTYPE html>
<html>
  <head>
    <title>My Website</title>
  </head>
  <body>

    <!-- your page content -->

    <!-- paste Yoosr widget here -->
    <script>
      window.yoosrSettings = { projectId: "YOUR_PROJECT_ID" };
    </script>
    <script src="https://app.yoosr.com/widget.js" async></script>
  </body>
</html>
```

<Callout variant="warning" title="Placement matters">
The snippet must go before `</body>`, not inside `<head>`. Placing it in the head can cause the widget to load before your page is ready.
</Callout>

### Step 3 — Test it

Open your website in a browser. You should see a circular chat button in the bottom-right corner.

Check that:

- The button is visible and clickable
- Clicking it opens the chat window
- You can type a message and see it appear in your Yoosr dashboard under **Monitor**

<Callout variant="tip" title="Use an incognito window for testing">
The widget remembers visitors using browser storage. Open an incognito window to simulate a brand-new visitor each time you test.
</Callout>

## What the widget does by default

Once installed, the widget behaves like this out of the box:

| Behavior | Default |
|----------|---------|
| Position | Bottom-right corner |
| Welcome message | Appears after 3 seconds |
| Pre-chat form | Disabled — visitors chat immediately |
| Language | English |
| Bot | None until you assign one |

## Using a website builder or CMS?

The snippet works on any HTML page. For specific platforms:

- **WordPress** — Paste the snippet in your theme's `footer.php` before `</body>`, or use a plugin like Insert Headers and Footers.
- **Shopify** — In your theme editor, open `theme.liquid` and paste before `</body>`.
- **Webflow** — Go to Project Settings → Custom Code → Footer Code and paste there.
- **Next.js / React** — Add the snippet inside a `useEffect` or use `next/script` with `strategy="beforeInteractive"`.

For all other cases: if you can edit the HTML of your page, you can install the widget.

## Widget not showing?

Run through this checklist:

1. Is the snippet placed before `</body>` (not in `<head>`)?
2. Does the `projectId` in the snippet match the one in **Settings → Widget Setup**?
3. Open your browser's DevTools (F12) → Console tab. Are there any red errors?
4. Is an ad blocker or browser extension blocking third-party scripts? Test with extensions disabled.

For more detailed troubleshooting, see [Widget not showing on my website →](/docs/troubleshooting/widget-not-showing).
