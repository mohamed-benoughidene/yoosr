# Getting Started with Yoosr

Yoosr is an **AI-powered customer support platform** that helps you manage conversations across multiple channels from a single dashboard. Whether you run a small business or an enterprise team, Yoosr gives you the tools to automate, streamline, and scale your support operations.

## What You Can Do

### Live Chat Widget

Embed a customizable chat widget on any website with a single snippet of code. The widget supports real-time messaging, file attachments, pre-chat forms, and automatic visitor identification.

### AI Chatbots

Connect your Yoosr project to 100+ LLM models via OpenRouter. The AI bot can answer common questions using your knowledge base, qualify leads, and escalate to human agents when needed.

### Bot Flow Designer

Build visual conversation flows with a drag-and-drop graph editor. Create automated workflows for FAQ routing, order status checks, appointment booking, and more — no code required.

### Multi-Channel Support

Reach your customers wherever they are. Yoosr supports:

- **Website Widget** — Embedded chat widget
- **Telegram** — Bot-based messaging
- **WhatsApp** — Business API integration
- **Facebook Messenger** — Page-based chat
- **Instagram** — DM and mention handling

All channels feed into the **same agent dashboard**, so your team never has to switch tools.

### Agent Dashboard

Your team gets a powerful workspace for managing conversations:

- Assign conversations to agents or departments
- Add labels for categorization (bugs, billing, VIP, etc.)
- Use canned responses for common replies
- View real-time metrics and activity logs

## Prerequisites

Before you begin, make sure you have:

1. A **Yoosr account** — sign up at [app.yoosr.com](https://app.yoosr.com/signup)
2. An **organization** — created automatically when you sign up via Clerk
3. A **project** — your support workspace (you'll create this next)

## Quick Start Path

| Step | What you'll do | Where |
|------|----------------|-------|
| 1 | Create a project | Dashboard |
| 2 | Configure your widget | Settings → Widget Setup |
| 3 | Embed the widget | Paste code on your website |
| 4 | Set up an AI chatbot | AI Settings |
| 5 | Invite team members | Organization Settings |
