# The contact profile

Every conversation in Yoosr has a contact profile visible in the right panel of Monitor and Chat. It shows everything Yoosr knows about the visitor — details you or your bot have captured, plus technical information collected automatically when the conversation started.

## The visitor info section

The first accordion section in the right panel — **Info** — shows the visitor's personal details. Every field here is editable. Click any field to edit it inline, then press Enter or click the checkmark to save.

| Field | What it holds |
|---|---|
| Name | The visitor's display name |
| Email | Their email address |
| Phone | Their phone number |
| Address | Their physical address |
| Note | A free-text note about this visitor |

Changes save immediately and are visible to all agents in your organization. There is no separate save button.

## The conversation details section

The second accordion section — **Conversation** — shows read-only metadata about the current conversation:

**Channel** — Where the conversation came from: widget, WhatsApp, Telegram, Messenger, or Instagram.

**Status** — The current state of the conversation: open (unassigned), assigned (being handled by an agent), bot (a bot is handling it), or resolved.

**Department** — The department this conversation is assigned to, if any.

**Priority** — The urgency level: Low, Normal, High, or Urgent. You can change the priority directly from this dropdown. It affects sort order in Monitor when sorted by priority.

**Assigned to** — Which agent or bot currently holds this conversation.

## The technical info section

The third accordion section — **Technical** — shows information captured automatically when the visitor started the conversation:

- When the conversation was created
- The visitor's browser language
- Their operating system and browser
- The page URL they were on when they opened the chat
- Their IP address

This section is read-only. It is useful for understanding the visitor's context — for example, confirming they are using a mobile device when they report a display issue.

## Saving a visitor as a contact

At the bottom of the right panel there is a button to save the visitor's details as a permanent contact record. This links the conversation to an entry in your Contacts section, where you can find the visitor again later.

If a contact record already exists for this visitor (matched by conversation ID), the button updates the existing record instead of creating a duplicate.

## Labels

Below the contact details, the right panel also shows the labels applied to this conversation. Use the **+** button to add a label from your project's label dictionary, or click **×** on any label badge to remove it. See [Labels →](/docs/agent-dashboard/labels  for how to manage your label dictionary.
