# Signature Verification

Every outbound webhook delivery from Yoosr is signed with **HMAC-SHA256**. You should verify this signature before processing the payload to ensure it genuinely came from Yoosr.

## How It Works

When Yoosr sends a webhook POST to your endpoint:

```
POST https://your-server.com/webhook
Content-Type: application/json
X-Yoosr-Event: message.create
X-Yoosr-Signature: sha256=<hex-hmac>
```

The `X-Yoosr-Signature` header contains an HMAC of the raw request body, signed with the per-subscription secret that was generated when you created the webhook subscription.

## Verifying in Node.js

```js
const crypto = require("crypto");

function verifySignature(payload, signature, secret) {
  const expected = "sha256=" + crypto
    .createHmac("sha256", secret)
    .update(payload)
    .digest("hex");

  return crypto.timingSafeEqual(
    Buffer.from(signature),
    Buffer.from(expected)
  );
}

// In your webhook handler:
app.post("/webhook", (req, res) => {
  const rawBody = JSON.stringify(req.body);
  const signature = req.headers["x-yoosr-signature"];
  const secret = process.env.YOOSR_WEBHOOK_SECRET;

  const isValid = verifySignature(rawBody, signature, secret);
  if (!isValid) {
    return res.status(401).send("Invalid signature");
  }

  // Process the event
  const event = req.body.event;
  console.log(`Received event: ${event}`, req.body.data);

  res.status(200).send("OK");
});
```

## Verifying in Python

```python
import hmac
import hashlib

def verify_signature(payload_bytes: bytes, signature: str, secret: str) -> bool:
    expected = "sha256=" + hmac.new(
        secret.encode(),
        payload_bytes,
        hashlib.sha256
    ).hexdigest()

    return hmac.compare_digest(signature, expected)

# In your Flask handler:
from flask import Flask, request

app = Flask(__name__)

@app.route("/webhook", methods=["POST"])
def webhook():
    signature = request.headers.get("X-Yoosr-Signature")
    secret = os.environ["YOOSR_WEBHOOK_SECRET"]

    if not verify_signature(request.data, signature, secret):
        return "Invalid signature", 401

    event = request.json["event"]
    print(f"Received event: {event}", request.json["data"])

    return "OK", 200
```

## Security Notes

| Practice | Why |
|----------|-----|
| **Constant-time comparison** | Prevents timing attacks that could leak the secret |
| **Verify before processing** | Rejects forged payloads early |
| **Store secrets securely** | Use environment variables or a secrets manager |
| **Rotate secrets periodically** | Regenerate the signing secret in Yoosr webhook settings |

<Callout variant="warning" title="Raw body matters">
When computing the HMAC, use the **raw request body** as a byte string — not the parsed JSON. In Express, access `req.body` before JSON parsing middleware, or use `rawBody`.
</Callout>

## Managing Secrets

Each webhook subscription has its own signing secret:

1. View the secret in **Dashboard → Settings → Webhooks**
2. Copy it to your server's environment variables
3. If compromised, regenerate it in Yoosr (all existing deliveries will fail until you update your server)
