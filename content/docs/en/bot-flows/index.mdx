# Bot flows

Bot flows are how you build automated conversation logic in Yoosr. You use a visual drag-and-drop editor called **Design Studio** to connect blocks — each block represents one step the bot takes.

## What you can build

- **FAQ bots** — Answer common questions automatically using your knowledge base
- **Triage flows** — Ask the visitor what they need, then route to the right department
- **Qualification flows** — Collect information before handing off to a human agent
- **Order tracking** — Let visitors check order status without agent involvement

## How it works

1. Create a bot from the **Bots** section
2. Open it in **Design Studio**
3. Add blocks from the palette — Reply, Condition, Capture Reply, Ask Knowledge Base, and more
4. Connect blocks with arrows to define the flow
5. Publish the bot and assign it to a project

## Key concepts

- A **bot** is the container — it has a name and is assigned to a project
- A **flow** is the graph of blocks inside the bot — it defines the logic
- Every bot has exactly one flow
- A project can have one bot assigned to it
