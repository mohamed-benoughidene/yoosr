# Visual Designer

The Design Studio is a visual graph editor built with **React Flow** (`@xyflow/react`). It lets you create, edit, and publish bot flows using a drag-and-drop canvas.

## Accessing the Design Studio

From your project dashboard, click **Design Studio** in the navigation. You'll see:

- A list of existing bot flows
- A **New Flow** button to create one
- Each flow's name, status (draft/published), and last modified date

## The Canvas

When you open a flow, you see:

| Element | Description |
|---------|-------------|
| **Canvas** | The main workspace where you arrange nodes |
| **Node Palette** | A sidebar with available node types to drag onto the canvas |
| **Minimap** | A small overview of your entire graph in the corner |
| **Zoom Controls** | Zoom in/out to focus on details or see the full graph |
| **Toolbar** | Save, Publish, Undo, Redo, and Delete actions |

### Navigation

- **Pan**: Click and drag the canvas background
- **Zoom**: Scroll wheel, pinch-to-zoom (trackpad), or the +/- buttons
- **Select**: Click a node to select it
- **Multi-select**: Shift+click multiple nodes

## Adding Nodes

1. Drag a node type from the **Node Palette** onto the canvas
2. Click the node to open its **configuration panel** on the right
3. Fill in the node's settings (varies by type)
4. Click **Save** on the node

## Connecting Nodes

1. Hover over a node's **output handle** (small circle on the right/bottom edge)
2. Click and drag to another node's **input handle**
3. Release to create a connection (edge)
4. Click the edge to add a **condition label** (e.g., "yes", "no", "pricing")

<Callout variant="tip" title="Plan before building">
Sketch your conversation flow on paper first. It's faster to iterate on the canvas when you know the structure.
</Callout>

## Node Configuration Panel

When you select a node, the right panel shows its settings:

- **Node Name** — Internal label (not shown to visitors)
- **Node Type** — Trigger, Message, Condition, Action, or End
- **Type-specific fields** — Varies by node type (see Nodes & Actions docs)

## Saving & Publishing

| Action | What it does |
|--------|-------------|
| **Save Draft** | Saves your changes without affecting the live bot |
| **Publish** | Makes this flow active — visitors will use it immediately |
| **Revert to Draft** | Returns to the last published version, discarding unsaved changes |

<Callout variant="warning" title="Publishing is immediate">
When you publish, the flow goes live for all new conversations. Existing conversations continue with their current state.
</Callout>

## Testing Your Flow

Use the **Test Widget** to interact with your published flow:

1. Open the test widget (link in Settings → Widget Setup)
2. Send a message that matches your Trigger node's condition
3. Verify the bot responds as configured
4. Test all branches of Condition nodes

## Best Practices

1. **Name your nodes** — "Welcome Message" is clearer than "Message Node 1"
2. **Use Comment nodes** — Add notes to complex sections of your graph
3. **Keep flows focused** — One flow per use case (e.g., "Order Status Flow", not one giant flow for everything)
4. **Test every branch** — Verify all Condition node edges lead to the right nodes
5. **Version management** — Save drafts frequently and publish only when ready
