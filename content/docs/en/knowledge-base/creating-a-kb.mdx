# Creating a knowledge base

A knowledge base is a collection of content — web pages, documents, or text — that your AI bot can search when a visitor asks a question. Instead of guessing, the bot finds the most relevant passage from your content and uses it to form an answer.

Each knowledge base belongs to a project. You can create multiple knowledge bases and connect different ones to different bots.

<Callout variant="info" title="Who can create a knowledge base">
Only admins can create or delete knowledge bases. All team members can view them.
</Callout>

## Create a knowledge base

1. In the left sidebar, select **Knowledge Base**.
2. Select **New knowledge base** (the **+** button at the top of the list).
3. Enter a **Name** for the knowledge base. Choose a name that describes the content — for example, "Product FAQ" or "Shipping Policy".
4. Optionally, enter a **Description** to remind your team what this knowledge base is for.
5. Select **Create**.

Yoosr creates the knowledge base and opens it so you can start adding content.

## What happens after you create a knowledge base

Your new knowledge base starts empty. It does not answer bot questions until you add at least one source and Yoosr finishes processing it. See [Adding sources](./adding-sources) for next steps.

## Managing multiple knowledge bases

You can create as many knowledge bases as you need. The sidebar on the Knowledge Base page lists all of them. Select any knowledge base name to open it and manage its sources.

To delete a knowledge base, select the trash icon next to it in the list. Deleting a knowledge base also removes all its sources and the embeddings derived from them. This action cannot be undone.
