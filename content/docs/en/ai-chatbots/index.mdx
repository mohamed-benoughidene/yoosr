# AI Chatbots

Yoosr's AI chatbots use large language models (LLMs) to automatically answer visitor questions, qualify leads, and provide 24/7 support — all from your knowledge base.

## What They Do

An AI chatbot in Yoosr can:

- **Answer questions** using your uploaded knowledge base documents
- **Qualify leads** by collecting visitor information before routing
- **Escalate to agents** when it can't resolve an issue
- **Work across all channels** — widget, WhatsApp, Telegram, Messenger, Instagram

## How It Works

```
Visitor sends message
    ↓
Is an AI bot enabled?
    ↓ Yes
Fetch relevant knowledge base context (RAG)
    ↓
Build prompt with system instructions + context
    ↓
Send to LLM via OpenRouter
    ↓
Parse response and send to visitor
    ↓
Can the bot resolve this?
    ↓ No                    ↓ Yes
Route to human agent    Continue conversation
```

### Key Components

| Component | Role |
|-----------|------|
| **LLM Model** | The AI engine (via OpenRouter) that generates responses |
| **Knowledge Base** | Your documents that the bot references for answers (RAG) |
| **System Prompt** | Instructions that define the bot's behavior, tone, and guardrails |
| **Smart Routing** | Logic that decides whether the bot answers or routes to an agent |

## Prerequisites

Before enabling an AI chatbot:

1. **OpenRouter API Key** — Set in your project's AI settings
2. **Knowledge Base** — At least one document source uploaded
3. **System Prompt** — Configured (defaults provided)

<Callout variant="warning" title="Cost awareness">
LLM calls cost money per token. Monitor your usage in the Token Usage dashboard. Set rate limits to control spending.
</Callout>

## Smart Routing

When a message arrives, Yoosr follows this routing logic:

1. **Check for an active bot flow** — If a visual bot flow is configured, execute it first
2. **Try the AI chatbot** — If no bot flow matches, the AI generates a response
3. **Fallback to agents** — If the AI can't answer (or is disabled), route to available agents
4. **Unassigned queue** — If no agents are available, the conversation waits in the queue
